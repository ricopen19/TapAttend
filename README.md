# TapAttend

タップして出席管理できる Web アプリ。Google Apps Script（GAS）上で動作し、
出欠データは Google スプレッドシートに保存される。
紙の教務手帳の「集計がめんどくさい」を解決します。

## できること

- 表形式の名簿にタップで出席状況を入力（出席・欠席・遅刻・早退・公欠・忌引・出停）
- 「＋」ボタンで今日の日付の列を追加（日付の手動修正も可能）
- 長押しで備考入力（公欠の理由など）
- 出席数・欠席数・出席率を自動計算
- CSV エクスポート（Excel に貼れる形式）
- JSON バックアップ（読み取り専用のスナップショット出力）

## データについて

入力したデータは Google スプレッドシート（学年組ごとに自動作成される専用ファイル）に保存されます。
名簿（出席番号・氏名）は別途用意した名簿マスタのスプレッドシートから読み取ります。
詳しくは [データの取り扱いについて](DATA_POLICY.md) をご覧ください。

**Tips**: 生徒名はイニシャルや出席番号だけでも運用できます（例：「A・H」「1番」）。
個人情報が気になる場合はこの方法がおすすめです。

## 使い方

### 0. 名簿マスタの参照先を設定する（初回のみ）

学年ごとに名簿マスタのスプレッドシートが異なる場合、出欠データスプレッドシート（「TapAttend出欠データ」）の「設定」タブに、学年番号と対応する名簿マスタのスプレッドシートIDを入力しておく。

| 学年 | スプレッドシートID |
|---|---|
| 1 | 1学年の名簿マスタのスプレッドシートID |
| 2 | 2学年の名簿マスタのスプレッドシートID |

「学年」は次のクラス作成時に入力する「学年組」の先頭の数字（例：`1-5` なら学年は `1`）で判定される。
年度更新で名簿マスタが変わった場合も、このタブのセルを書き換えるだけでよい。詳細は [gas/README.md](gas/README.md) を参照。

### 1. クラスを作る

ホーム画面で「学年組」（名簿マスタのシート名と一致させる）と「教科名」を入力して「追加」。
例：学年組「1 - 1」、教科名「数学I」

対応する名簿マスタのスプレッドシートIDが「設定」タブに登録されていない、または名簿マスタ側に該当タブが無い場合はエラーになる（クラスは作られない）。

### 2. 生徒を確認する

クラスの「生徒」ボタンから、名簿マスタ由来の出席番号・氏名を確認できます（このアプリからは編集不可）。
番号・氏名はクラス作成時に名簿マスタからコピーされ、以後は自動更新されない。名簿マスタ側で生徒の
追加・氏名修正があった場合は、この画面の「名簿を再取り込み」ボタンを押して反映する。
生徒ごとのメモ（特徴・出来事など）だけ編集できます。

### 3. 出席を入力する

クラス名をタップすると出席簿が開きます。作成直後は授業日が0件なので、生徒一覧と集計列（出席・欠席など）だけが表示され、出欠を入力する列はまだ無い。「＋ 授業日追加」を押して初めて入力列が現れる。

| 操作 | 動作 |
|---|---|
| 「＋ 授業日追加」 | 今日の日付で列を追加 |
| セルをタップ | 出席 → 欠席 → 遅刻 → 早退 → 公欠 → 忌引 → 出停 → 出席... の順に切り替え |
| セルを長押し | 備考を入力（備考があるセルは青枠で表示） |
| 日付をタップ | 日付を修正 |
| 日付下の「×」 | その授業日の列を削除 |

右端の列に出席数・欠席数・出席率がリアルタイムで表示されます。
タップ操作は一旦手元に反映され、少し遅れてスプレッドシートに保存されます（通信のたびに待たされないための仕組み）。

### 4. データを出力する

- **CSV出力**: Excel で開ける出席簿形式のファイルをダウンロード
- **バックアップ**: 全クラスのデータを JSON ファイルとして出力（読み取り専用。復元機能はなし）

## 動作環境

Google Workspace（組織アカウント）でログインしたブラウザから、GAS の Web App URL にアクセスして使う。
iPad / iPhone / PC いずれも Chrome・Safari で動作確認済み。

## デプロイ

GAS へのデプロイ手順は [gas/README.md](gas/README.md) を参照。

## 開発

```bash
npm install
npm run dev        # ローカルでのUI確認（データ操作はGAS上でのみ動作）
npm run build:gas  # GASデプロイ用の単一HTMLを gas/index.html に出力
```
